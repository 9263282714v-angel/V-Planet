# V-PLANET

Витрина мастерской ароматических свечей и диффузоров. Готовые товары: диффузоры, свечи, парфюм, гипс. Расходники и сырьё на этот сайт не вынесены.

Откройте `index.html` локально или отдайте папку как статический сайт.

Цены и описания взяты с [v-planet.ru](https://www.v-planet.ru). Заказ с новой витрины — заявка, оплату подтверждает мастерская.
